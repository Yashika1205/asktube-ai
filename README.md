# ⚡ AskTube AI

AI-powered YouTube chatbot that lets you chat with any YouTube video instantly.

## Features
- 💬 Chat with any YouTube video
- 📋 Auto summary & key points
- ⏱️ Timestamp-aware topic search
- 🌐 Hindi & English video support

## Tech Stack
- LangChain + RAG
- FAISS Vector Database
- HuggingFace Embeddings
- Groq LLaMA 3.1
- Streamlit
